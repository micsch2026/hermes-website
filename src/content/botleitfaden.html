  "asset": "EURUSD",
  "direction": "long",
  "trigger_condition": "Preis über 1.0850",
  "invalidation": "Preis unter 1.0820",
  "tp_logic": "TP bei 1.0880",
  "conviction": 0.78,
  "confidence": "medium",
  "source": "strategist",
  "status": "pending",
  "expires_at": "2026-05-09T22:00:00Z",
  "reasoning": "...",
  "monitoring_interval": 5
}

Lifecycle

StatusBedeutungWer setzt?
pendingThese erzeugt, wartet auf ReflectorStrategist oder Scanner
armedReflector approved/revised, Trigger wird geprüftReflector oder System
filledTrigger gefeuert, Trade ausgeführtExecutor Daemon
rejectedReflector hat abgelehntReflector
blockedInstitutionelle Guard hat blockiertExecutor Daemon
expiredexpires_at erreicht ohne AusführungAuto

Deduplikation (Conviction-basiert)

  • Neue These mit höherer Conviction → alte wird ersetzt
  • Neue These mit gleicher/niedrigerer Conviction → wird übersprungen
  • System-Thesen (Scanner) haben niedrigere Conviction (0.50-0.65)

6. STRATEGIST — Die KI-Analyse

Der Strategist entscheidet welche Assets gehandelt werden. Er arbeitet im Layer-Modell:

Layer 1: Macro (DXY, US10Y, VIX, F&G)      → Markt-Regime bestimmen
Layer 2: Sentiment (News, COT)              → Smart-Money-Richtung
Layer 3: Price Action (Scanner-Daten)       → Technische Entry-Points
Layer 4: Chronos Forecast (ML)              → Datengetriebener Bias pro Asset

Trigger-Format (STANDARDISIERT)

WICHTIG: Der Executor muss den Trigger EXAKT parsen. Format ist strikt:
  • LONG: "Preis über X.XXXX"
  • SHORT: "Preis unter X.XXXX"
  • KEINE UND-Klauseln, KEINE Indikatoren im Trigger
  • INVALIDATION genauso einfach: "Preis unter X.XXXX" (Long) / "Preis über X.XXXX" (Short)

7. RISIKO-MANAGEMENT

Safety Nets

RegelSchwelleAktion
Tages-Loss-Limit-3% Equity (~15 EUR)Trading-Stop für den Tag
Cooldown3 Verluste in FolgeTrading pausiert bis Strategist-Neubewertung
Emergency StopEquity < 10% von Reference-BalanceAlle Trading gestoppt
Weekend-BlockFr 21:00 - So 22:00 UTCKeine neuen Orders
News-BlackoutFOMC/NFP: 60min vorherKein Entry während High-Impact Events
VIX-Kill-SwitchVIX > 35Keine neuen Entries
WatchdogDaemon >60s nicht reagiertEmergency Close aller Positionen

Position-Sizing (Kelly-basiert)

  • Basis: Quarter-Kelly aus historischer Performance
  • VIX-Scaling: Calm (×1.15) → Neutral (×1.0) → Elevated (×0.75) → Stress (×0.5)
  • Conviction-Overlay: 0.55→0.6×, 0.75→1.0×, 1.0→1.5×
  • Hard Limits: Min 0.3% Equity, Max 5% Equity pro Trade
  • Margin-Limit: Max 30% Equity als Margin

Atomic SL (relativeStopLoss)

SL/TP wird atomar mit der Market-Order gesetzt:

req.relativeStopLoss = sl_points
req.relativeTakeProfit = tp_points
req.maxSlippageInPoints = 30

Pitfall: relativeStopLoss nutzt pointSize, NICHT Pips. EURUSD: point=0.00001, 14 Pips = 140 Points.
